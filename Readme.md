# Solana Token Management Bot

A Telegram bot for managing Solana tokens with automated selling, community management, and social media marketing.

## Features

- Position monitoring
- Automated token selling
- Community censorship
- Twitter marketing integration
- Multi-token support

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Configure environment variables in `.env`
3. Run setup script: `bash setup.sh`
4. Start bot: `bash start.sh`

## Commands

- `/start` - Start the bot
- `/position` - Check current position
- `/balance` - Check wallet balance
- `/pool` - Check pool information
- `/sell [percentage]` - Execute sell
- `/add_token [address]` - Add new token to monitor
- `/position_all` - Check all token positions
